# TrekPioneer - 徒步先锋队

**版本**: v2.0  
**Slogan**: 每一步，都算数  
**平台**: Flutter (iOS/Android)

---

## 🏔️ 项目简介

徒步先锋队是一款专业的徒步运动社交 App，提供：
- AI 定制训练计划
- 团队目标协作
- 队友数据深度探索
- 轨迹记录与回放
- 运动数据分析

---

## 🚀 快速开始

### 环境要求
- Flutter SDK: 3.24.0+
- Dart: 3.5.0+
- iOS: 12.0+
- Android: API 21+

### 安装依赖
```bash
flutter pub get
```

### 运行 App
```bash
flutter run
```

### 构建 Release APK
```bash
flutter build apk --release
```

### 构建 iOS
```bash
flutter build ios
```
